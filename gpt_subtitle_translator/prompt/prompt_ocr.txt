# Advanced Subtitle Translation Task (OCR-Extracted)

Task: Translate video subtitles to {target_language}, **extracted via OCR from hardcoded subtitles**, to **fluent, natural-sounding {target_language}**. The original subtitles were written by humans but may contain **occasional OCR artifacts** (character recognition errors, noise symbols, spacing issues).

## Input Format
- Subtitles are presented between START and END markers.
- Each subtitle consists of a unique `<subtitle_id>subtitle_text</subtitle_id>`.

## Core Translation Philosophy

**Primary Goal:** Produce dialogue that sounds like it was originally written by a native {target_language} speaker.

**Decision Hierarchy** (when translation choices conflict):

1. **Semantic Accuracy** - Preserve the core meaning, emotional tone, and speaker intent
2. **Natural Expression** - Express it as a native {target_language} speaker naturally would
3. **Structural Fidelity** - Source sentence structure is flexible; adapt as needed

**Core Principle:** Your constraint is meaning, not form. If source structure produces unnatural {target_language}, restructure freely.

## What to Preserve vs. Adapt

**MUST Preserve:**
- Core meaning and intent
- Emotional tone (anger, affection, sarcasm, etc.)
- Formality level and social register
- How this fits into the ongoing dialogue

**SHOULD Adapt:**
- Sentence structure and word order
- Tense/aspect (use what {target_language} naturally uses for that situation)
- Explicit vs. implicit subjects/objects
- Idioms (find {target_language} equivalents with same meaning/weight)
- Placement of emphasis and intensity markers

## Key Translation Guidelines

**Naturalness Test:** If your translation sounds "translated" (stilted, awkward, or mirroring source structure unnaturally), restructure it. Ask: "Would a native speaker actually say this?"

**Tense/Aspect:** Use the tense that sounds natural in {target_language} for the situation, even if different from source.

**Word Order:** Follow {target_language} syntax patterns. Don't preserve source word order if it produces awkward {target_language}.

**Idioms:** Identify idiomatic expressions and find {target_language} equivalents that convey the same meaning and emotional weight, rather than translating literally.

**Context:** Use surrounding subtitles to maintain consistency in tense, pronouns, formality, and conversational flow.

**OCR Artifacts:**
- **Character-level errors:** Correct silently (l/I confusion, 0/O confusion, rn/m confusion, spacing issues)
- **Non-linguistic noise:** Remove entirely (random digit/symbol strings, misrecognized UI elements, obvious garbage)
- **Intentional unclear speech:** Preserve patterns like stuttering, trailing off, or mumbling if they appear intentional
- Only mention in "thoughts" if there's genuine ambiguity about whether something is an error or intentional

## Documentation: The "Thoughts" Field

Use "thoughts" to explain **non-obvious translation choices only**:
- Significant restructuring for naturalness
- Tense/aspect selection based on {target_language} patterns
- Idiom adaptation or cultural localization
- Resolving ambiguity using context
- Formality or register decisions
- Choosing between multiple valid natural options

**Use empty string `""` for straightforward translations.**

## Output Format

```json
[
  {"id": 1, "original": "source text", "thoughts": "", "translation": "natural {target_language}"},
  {"id": 2, "original": "source text", "thoughts": "explanation of choice", "translation": "natural {target_language}"}
]
```
