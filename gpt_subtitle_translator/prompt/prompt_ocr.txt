# Advanced Subtitle Translation & Adaptation Task

Task: Translate video subtitles to {target_language}, **originating from OCR extraction**, to **fluent, natural-sounding {target_language}**. The original subtitles **will frequently contain OCR artifacts (visual typos), random noise characters, spacing errors, and rigid source-language syntax.** Your primary goal is to **recover the intended meaning** and produce subtitles that are contextually appropriate, clear, and engaging for a {target_language}-speaking audience.

## Input Format
- Subtitles are presented between START and END markers.
- Each subtitle consists of a unique `<subtitle_id>subtitle_text</subtitle_id>`.

## Core Instructions & Philosophy
1.  **Prioritize Intended Meaning & Naturalness:** Your translation must prioritize natural dialogue flow and the *likely intended meaning* in {target_language} over strict, literal adherence to the source. The translation should sound like something a native {target_language} speaker would naturally say in that situation. **Do not mimic the sentence structure of the source language if it sounds stiff in {target_language}.**
2.  **Embrace Proactive Error Correction (Visual & Structural):** **Assume the source input is imperfect.** Actively look for and correct OCR errors.
    *   **Visual Errors:** Look for characters that resemble each other (e.g., '1' vs 'l', '5' vs 'S', 'rn' vs 'm'). Correct these silently.
    *   **Noise Removal:** Remove random symbols (e.g., `|`, `_`, `>>`, `...`) resulting from bad OCR scanning.
    *   **Syntax "Errors":** Treat awkward, literal source phrasing as an error. Rewrite it to be idiomatic.
3.  **Context is King:** Use surrounding subtitles to infer meaning when the source text has severe OCR damage. Use context to confirm the correct word when a typo creates ambiguity.
4.  **Cultural Localization:** Adapt cultural references, idioms, or expressions to be natural to a general {target_language}-speaking audience. **Never translate idioms literally.**
5.  **Leverage Source Language Understanding:** When encountering a nonsense word, check if it is a **visual misrecognition** of a valid source word.

## Detailed Instructions
- Translate each subtitle to {target_language}, preserving the speaker's intent, tone, and relevant cultural nuances.
- **Use Contractions:** High-quality subtitles use natural speech patterns (e.g., "I'm," "don't," "it's") rather than robotic forms ("I am," "do not").
- **Preserve Line Breaks:** Maintain the line breaks (`\n`) from the original subtitle formatting in your translation exactly as they appear.
- **Handling OCR Errors:**
    - For **obvious** visual OCR errors (e.g., `Th1s` -> `This`, `H0la` -> `Hola`) or noise removal, **correct them silently**. Do **NOT** use the "thoughts" field.
    - Only use "thoughts" if the OCR error creates genuine ambiguity that requires context to resolve.
- **Handling Idioms:**
    - If a phrase is an idiom in the source language, find the equivalent **meaning** in {target_language}. Explain the specific idiom in "thoughts."

## Output Format
```json
{
  "language": "{target_language}",
  "subtitles": [
    [1, "", "natural {target_language}"],
    [2, "reasoning only if needed", "natural {target_language}"]
  ]
}
```

- `language`: The target language name
- Each subtitle is a tuple: `[id, thoughts, translation]`
  - `id`: The subtitle number matching the original
  - `thoughts`: Reasoning **only when needed to arrive at** the translation (error correction, idiom selection, disambiguation). Use empty string `""` for straightforward translations.
  - `translation`: Your translation into {target_language}, preserving any line breaks from the original

**All translations MUST be in {target_language}.**
